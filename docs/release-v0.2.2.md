# v0.2.2 — 增加远程与共享画面启动入口

默认屏幕捕获保护会将软件主窗口从远程或共享画面中排除，因此任务栏有图标但共享桌面看不到窗口。v0.2.2 增加允许当前会话被捕获的远程入口；用户已在原下载目录确认共享画面能够看到主窗口。

- 远程首次使用：**Setup-Remote.cmd / 远程首次配置.cmd**。
- 远程日常使用：**Launch-Remote.cmd / 远程启动.cmd**。
- 本机显示器使用：**Setup.cmd / 首次配置.cmd**，以后 **Launch.cmd / 启动软件.cmd**，默认屏幕保护继续开启。

切换到远程模式时会请求正常关闭受保护的旧实例并重开；未保存内容导致软件拒绝退出时，保留提示，不强制终止。退出远程软件后用普通入口重新启动，即恢复屏幕保护。启动还检查窗口在显示器范围内，恢复最小化、旧隐藏窗口和移出屏幕的窗口。

新用户下载 **TKYP-Windows-x64-v0.2.2.zip** 和 **TKYP-Chrome-Edge-v0.2.2.zip**。完整软件包含独立 Python/CPU 推理环境及两模型。已有软件下载 **TKYP-Launch-Fix-v0.2.2.zip**，在原 TheyKnowYourPasswords 文件夹的上一级解压并覆盖启动文件，无需重新下载模型。**SHA256SUMS.txt** 提供三个附件校验值。

实际 Windows CMD 验收使用独立空白配置，不读取个人口令库或截图；包括远程捕获标志为 0、普通标志为 17、正常重开、重复启动、最小化、屏幕外恢复、注册及错误提示停留。具体计数与发布复核见 docs/launch-acceptance-v0.2.2.json 和 docs/release-publication-v0.2.2.json。

桌面程序、插件执行文件、算法和中性命名模型保持原版本身份；此前真实模型及 Chrome/Edge 各 32 项闭环对应相同组件。主口令设置、加载插件及个人库关联由用户首次完成。PSM 与 PARD 独立展示，未标定结果不宣称低风险；CPU 历史复检可显式选择 30/120 秒预算。
