# 首期威胁模型

历史集合只在已解锁宿主与本地算法子进程内出现。浏览器后台仅在关联、来源校验和用户触发请求中持有本次候选；内容脚本只接收用户要求填入当前网站的候选或脱敏通用强度。日志、缓存、报告和截图不记录口令、历史、主密钥或派生密钥。

首期防护覆盖持久化泄露、日志泄露、错误站点填充、伪造扩展请求、算法失败误判、过期异步结果和未经确认的凭据覆盖。它不声称抵御已完全控制本机进程或能读取目标网页内存的攻击者；用户主动填入页面的口令仍可被该页面读取。

算法服务只使用标准输入输出，不监听网络端口，不读取代理配置，不发起出站请求。缓存只保存 RankGuess 参考概率和猜测次数数组；候选、历史和主密钥不得落盘。

## 候选来源与文档生命周期

候选绑定浏览器连接、页面、来源、账号、目标条目、数据库会话及修订。扩展另以每个顶层内容文档的随机 `documentToken` 区分同一标签页中的文档实例。后台消息固定发送到顶层 frame，并在浏览器提供时指定 `documentId`；内容脚本在写入字段前同步核对本扩展发送方、`expectedOrigin` 与文档令牌，校验与 DOM 写入之间没有异步等待。这使后台检查后的导航不能把候选填入新文档，亦覆盖不提供文档 ID 时的文档实例校验。

导航会推进标签页请求序号；跨源或非网页导航撤销候选，同源成功跳转仅保留用户确认保存所需状态，新文档不能重填旧候选。推荐与准备响应必须仍匹配请求序号、输入修订、来源、文档令牌及已解锁关联的数据库。断连、锁库和解锁通知清除扩展候选与旧请求状态，即使之后重新关联同一数据库，也不接受原请求的迟到响应。

## 多页面撤销与迟到响应

页面取消仅作用于匹配的连接、`pageId` 和 `origin`；若携带令牌，还必须匹配该精确令牌。空令牌不能用于清空整条连接；扩展无待处理令牌时不发送取消 RPC。断连采用连接级清理，清除该连接所有候选与请求登记；锁库等全局状态变化清理所有登记。

异步请求在宿主具有独立 generation。较新请求、常规页面取消和生命周期清理使旧 generation 失效，宿主在替换候选前拒绝迟到评估，避免旧响应覆盖新候选。扩展丢弃迟到响应时，使用原页面、来源、精确候选令牌及 `invalidateRequests=false` 只回收旧令牌，不推进宿主输入修订或使新 generation 失效。页面级隔离与异步请求校验分别防止多标签页之间的误撤销和同页面请求乱序。

2026-10-22 的回归覆盖上述来源、导航与撤销竞争；浏览器层使用真实 Chrome/Edge 文档路由和生产扩展脚本，Native Messaging 与模型使用安全桩，宿主业务另由 Qt 测试验证。范围和可复核摘要见 [validation-report.md](validation-report.md) 与 [security-regression-2026-10-22.json](security-regression-2026-10-22.json)。这组验证不替代真实模型、真实加密关联和打包后的完整闭环验收。
