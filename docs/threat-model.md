# 首期威胁模型

历史集合只在已解锁宿主与本地算法子进程内出现。浏览器后台仅在关联、来源校验和用户触发请求中持有本次候选；内容脚本只接收用户要求填入当前网站的候选或脱敏通用强度。日志、缓存、报告和截图不记录口令、历史、主密钥或派生密钥。

首期防护覆盖持久化泄露、日志泄露、错误站点填充、伪造扩展请求、算法失败误判、过期异步结果和未经确认的凭据覆盖。它不声称抵御已完全控制本机进程或能读取目标网页内存的攻击者；用户主动填入页面的口令仍可被该页面读取。

算法服务只使用标准输入输出，不监听网络端口，不读取代理配置，不发起出站请求。缓存只保存 RankGuess 参考概率和猜测次数数组；候选、历史和主密钥不得落盘。
